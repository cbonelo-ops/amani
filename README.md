# Amani Yangu — website refresh

Static 4-page site for [Amani Yangu](https://amaniyangu.com) — counselling & coaching "for your peace & well being".

| Page | File |
|---|---|
| Home | `index.html` |
| About Us | `about.html` |
| Services | `services.html` |
| Bookings | `bookings.html` |

- **Brand:** yellow `#FFCB04` / `#FFF100` and black, per the Amani Yangu logo breakdown. Headings use Barlow Condensed (Google Fonts) as a free stand-in for CA Geheimagent Bold.
- **Images:** `images/` — logo, founder photo and hero/coffee/couple photos from the current site; supporting photos from Unsplash (free under the Unsplash License).
- **Booking form:** front-end only for now (shows a thank-you message). Connect it to a form handler or email before going live.

## SEO setup
- Keyword-led titles, meta descriptions and H1s per page (Christian counselling & coaching, Glenwood, Durban, online across South Africa).
- LocalBusiness schema (address, phone, hours) on the home page; `sitemap.xml` and `robots.txt`.
- Canonical URLs point to **https://amaniyangu.com/** so the GitHub Pages demo isn't indexed as a duplicate.
- WhatsApp click-to-chat button (082 899 2831).
